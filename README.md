# SDPSimulator

This repository now includes a habit tracker template that can be opened in Excel.

## Files
- `habit_tracker_template.csv` — daily habit log with built-in analysis columns and example habits.

## How to use in Excel
1. Open `habit_tracker_template.csv` in Excel.
2. Optionally format the data as a Table.
3. Enter one row per day.
4. Use `1` for completed habits and `0` for missed habits.
5. Replace the sample habits with your own routine.

## Included analysis
- Daily completion count
- Daily completion percent
- Weekly grouping column
- Notes column for journaling/context
